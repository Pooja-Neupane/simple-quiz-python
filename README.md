# 🧠 Simple Quiz Game in Python

A console-based quiz game developed in Python. This program uses dictionaries to store questions, multiple-choice options, and correct answers. It evaluates the user's input, calculates the score, and gives performance feedback.

## ✅ Features

- Multiple-choice questions stored in a structured format (dictionaries)
- Interactive quiz flow with instant feedback
- Score calculation and performance-based message at the end

## 💻 Technologies Used

- Python 3
- Dictionaries and Lists
- Conditional Statements & Loops

## 🛠️ How to Run

1. Copy or clone the code into a Python file (e.g., `quiz_game.py`)
2. Make sure Python 3 is installed on your system
3. Run the script:
   ```bash
   python quiz_game.py
